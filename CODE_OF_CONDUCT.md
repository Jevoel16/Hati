# Code of conduct

Hati is built by a group of four, and anyone who opens an issue or pull request joins that group for a while. Treat each other that way.

## Expected

- Be respectful, including when you disagree about code.
- Give feedback on the work, not the person.
- Assume good intent and ask before you assume.

## Not accepted

- Harassment, insults or discriminatory jokes.
- Publishing someone's private information.
- Sexual language or imagery.

## Enforcement

Report a problem to the maintainer through [github.com/Jevoel16](https://github.com/Jevoel16). Reports are kept private. The maintainer may remove comments, close issues or block accounts that break these rules.
